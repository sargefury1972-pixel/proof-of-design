How it works
  1. Fingerprint. Your browser calculates the file's SHA-256 — a unique 64-character code. Change one pixel and the code changes completely.
  2. Stamp. Only that code (plus your optional title) is written to the BSV blockchain, which time-stamps it in a block.
  3. Prove. Anyone can later drop the same file into Verify with the transaction ID to see it matches — and when it was recorded.

What verification proves

If the fingerprints match, this exact file existed no later than the block time of that transaction. The block time is set by the BSV network, not by us — so it can't be back-dated.

The tool also recognises other timestamp formats that store a SHA-256 in an OP_RETURN output.

Stamping key

A small, separate key that lives only in this browser and pays the network fee for each stamp. Never send your main savings here — a few pence of BSV covers thousands of stamps.

Back it up. This key exists only in this browser. Clearing your browser data deletes it (and any BSV on it). Download a backup and keep it somewhere safe — anyone with the backup can spend the funds on it.

Or use your BSV wallet beta

If you run a wallet that supports the BRC-100 standard (for example BSV Desktop / Metanet Desktop on this computer), the stamp can be paid and signed by your wallet instead — it will ask you to approve each one. Your wallet's keys never touch this page.

How much to put on it?

Each stamp costs about 30 satoshis in network fees.

100,000 sats (0.001 BSV) covers ~3,000 stamps and is worth about 1–2p.

Send from any BSV wallet (HandCash, Yours, RockWallet, an exchange…). Only send BSV — not BTC or BCH.

Privacy

Files are hashed in your browser and never uploaded. The fingerprint, title and time are public on the blockchain forever. Balance lookups and broadcasts go to WhatsOnChain and GorillaPool ARC.
